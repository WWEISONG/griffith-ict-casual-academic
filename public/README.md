# Static assets

## griffith-logo.svg

Place the official Griffith University logo here, named exactly
`griffith-logo.svg`, and it appears automatically on the landing page, the
sign-in and register pages, and in the application header.

Get the approved asset from Griffith's brand resources rather than copying it
from a web page — Marketing publishes correct versions with the right clear
space and colour variants for staff to use.

Until the file is present, the interface falls back to a plain "Griffith"
wordmark. That is deliberate: an approximated university crest is worse than
no crest.

A `.png` also works, but change the extension in `src/components/ui/Brand.tsx`
to match.
